Cavity parameters

Resonator, on-resonance power transfer, the TEM₀₀ mode and the round-trip ray matrix, computed from the parameters on the left.

Method and changes from the MATLAB version

Equations

  • Free spectral range FSR = c / (2nL); amplitude reflectivities ri = √ℛi, transmissions Ti = 1 − ℛi − lossi.
  • Finesse from the exact half-maximum condition 𝓕 = π / [2 arcsin((1 − r₁r₂) / (2√(r₁r₂)))]; linewidth δν = FSR/𝓕.
  • On resonance T = T₁T₂/(1 − r₁r₂)² and Pcirc/Pin = T₁/(1 − r₁r₂)².
  • gi = 1 − L/Ri; spot sizes w₁² = (λL/πn)·√(g₂ / (g₁(1 − g₁g₂))), waist w₀² = (λL/πn)·√(g₁g₂(1 − g₁g₂)) / |g₁ + g₂ − 2g₁g₂| located z₁ = L g₂(1 − g₁)/(g₁ + g₂ − 2g₁g₂) from M₁ (Siegman, Lasers, ch. 19).
  • One-way Gouy phase ψ = arccos(sgn(g₁)·√(g₁g₂)).
  • Round-trip ray matrix from M₁: M = M(R₁)·P(L)·M(R₂)·P(L) with M(R) = [1, 0; −2/R, 1]; flat mirrors use curvature 1/R = 0, so no Inf arithmetic is needed.

Corrected

  • FSR was written n·c/(2L); the refractive index belongs in the denominator.
  • Output_parameters.m inserted power reflectivities where amplitudes are required, giving 𝓕 = 560 instead of 1120 for ℛ = 0.9972 (and twice the linewidth).
  • The ray-matrix element M₂₁ used the spacer bore radius instead of R₂ (det M = 6.91 instead of 1), and flat mirrors set M₁₁ = 0 instead of its true limit.
  • g was recovered as (|A + D|/2 + 1)/2; the absolute value gives a wrong result whenever g₁g₂ < ½ (a confocal cavity reported g = 1).
  • The tilted-etalon quantity “FSR_angle” with a fixed 0.1 rad tilt was removed: it does not describe a spherical-mirror cavity.

Stability

Where your cavity sits on the g₁–g₂ diagram, which lengths are stable for your mirrors, and how sensitive the stability parameter is to small changes.

Method and changes from the MATLAB version
  • A two-mirror resonator has a confined Gaussian mode for 0 < g₁g₂ < 1; the boundaries g₁g₂ = 0 and 1 are marginal.
  • With fixed mirrors g₁g₂(L) = (1 − L/R₁)(1 − L/R₂), which crosses 0 at L = R₁, R₂ and reaches 1 at L = R₁ + R₂.
  • The change for a length step is evaluated exactly as −ΔL(1/R₁ + 1/R₂) + (2LΔL + ΔL²)/(R₁R₂), avoiding the subtraction of nearly equal numbers.

Corrected

  • The diagram now plots your cavity; the original only drew fixed reference points.
  • Cavity-type presets: “Hemi-spherical” used R = 2L (it is R = L) and “Plane-concave” used R = L/2, which is unstable (g₁g₂ = −1). “Concave-concave” sat on the stability boundary and was replaced by a stable asymmetric example.
  • The sensitivity plots used a hard-coded L = 0.485 m, a hard-coded offset g = 0.515 and R₂ = ∞, and subtracted nearly equal numbers at the 10⁻¹⁶ level; negative results disappeared from the log axes.

Method and changes from the MATLAB version
  • Resonances νq,mn = FSR·[q + (m + n + 1)·ψ/π]; order N = m + n is offset from TEM₀₀ by (Nψ/π mod 1)·FSR.
  • Relative transmission at the TEM₀₀ frequency 1 / (1 + F sin²(Nψ)), with the coefficient of finesse F = 4r₁r₂/(1 − r₁r₂)².
  • Second-moment radius of order N: w√(N + 1); TEM₀₀ power outside an aperture of radius a: exp(−2a²/w²).

Corrected

  • The Gouy phase used arccos(+√(g₁g₂)), which is wrong when g₁, g₂ < 0 — including the default near-concentric cavity — and mirrored every mode frequency inside the FSR.
  • Mode frequencies were folded by adding −1 … −6 FSR, so orders more than 7 FSR away were lost; a proper modulo is used now.
  • A stale stored finesse (2093) was used instead of the value implied by the mirror reflectivities (1120).
  • Mode pictures used hard-coded weights and a normalisation that multiplied instead of divided by √(2mm!w₀); mode sizes were fixed at 381/438 µm. Both now follow your cavity.
  • One script read matlab\sankalpa\dt.xlsx, a hard-coded Windows path.

Brownian thermal noise

Length fluctuations of spacer, mirror substrates and coatings from the fluctuation–dissipation theorem, and the flicker floor they set on the laser's frequency stability.

Method and changes from the MATLAB version
  • Spacer S = (4kBT/ω)·L φsp / (Esp π(R² − r²)) (Kessler et al. 2012, including the bore).
  • Each substrate S = (4kBT/ω)·(1 − σ²) φsub / (√π E w), w the 1/e² spot radius (Numata et al. 2004).
  • Each coating Scoat = Ssub·(2/√π)·(1 − 2σ)/(1 − σ)·(φc/φsub)·(d/w), assuming coating elasticity close to the substrate's.
  • Fractional frequency Sy = Sx/L²; for flicker noise the Allan deviation is flat at σy = √(2 ln2 · f · Sy(f)).

Corrected

  • The curve labelled “fractional frequency instability” was √(2 ln2 · Sy), missing the factor f. It therefore fell as 1/√f and agreed with the true flat floor only at 1 Hz.
  • The legend always read “R₁ = 1 m & R₂ = ∞” regardless of the inputs.

Thermal expansion

Effective expansion of the bonded mirror–spacer assembly, the cavity's zero-crossing temperature, and the resulting frequency drift with temperature.

Spacer expansion

Mirror substrate expansion

Coupling and display

Method and changes from the MATLAB version
  • Effective coefficient of a cavity with two bonded mirrors of radius Rm: αeff = αs + 2δ(Rm/L)(αm − αs) (Legero, Kessler, Sterr, JOSA B 27, 914, 2010). δ ≈ 0.37 for a 32 mm spacer diameter and approaches 0.49 for wide spacers; ULE rings on the mirror backs bring it close to 0.
  • Zero-crossing glass α = a(T − T₀) + b(T − T₀)²; fused silica α ≈ 500 × 10⁻⁹/K + 2.2 × 10⁻⁹/K² · (T − 20 °C).
  • ΔL/L = ∫αeff dT (exact for the polynomial models); Δν = −ν ΔL/L.

Corrected

  • The fractional length change was computed as αeff·ΔT instead of the integral, twice the correct value near the zero crossing.
  • One script gave the fused-silica mirrors a CTE of 2.2 × 10⁻⁹·ΔT, dropping the 500 × 10⁻⁹/K offset, so the large shift of the zero crossing (−28 K for the default cavity) was missing; the second script used constant values. Both now use one model.
  • dν/dT was divided by (1 + αeffT₀) with T₀ in kelvin and lost its sign; the g-factor change used new L for g₁, old L for g₂ and a hard-coded 0.515.
  • The df/dT matrix was a hard-coded table for L = 0.485 m at 1064 nm; it is now computed. The CTE and Q legends were swapped.

Method and changes from the MATLAB version
  • Radiation between an inner body (area Ai, emissivity εi) and its enclosure (Ao, εo), linearised: G = 4σT³ / [1/(Aiεi) + (1/Ao)(1/εo − 1)]. Conduction G = N k A/ℓ. Parallel paths add.
  • Network C₂Ṫ₂ = G₁₂(T₁ − T₂) + G₂₃(T₃ − T₂), C₃Ṫ₃ = G₂₃(T₂ − T₃) + G₃c(Tc − T₃), CcṪc = G₃c(T₃ − Tc), solved exactly with the matrix exponential; periodic attenuation from (iωI − A)⁻¹B.
  • The cavity's heat capacity and area follow from the spacer and mirror dimensions and the material densities.

Corrected

  • The “combined” model averaged the radiation-only and conduction-only responses; heat paths in parallel add their conductances. It also used the wrong surface areas for the second stage and a heat capacity of 210 instead of 900 J/(kg·K).
  • The P1 → P3 oscillation used a single pole with τ₁ + τ₂, which overstates the residual swing about 3× at a 50 h period, and its time constants were typed in rather than computed. Coupling back from the inner shield is now included.
  • The axis labelled “fluctuation period” was elapsed time.

Pressure effects: residual gas and radiation pressure

Two non-thermal effects on the resonance: refractive-index changes of the residual gas, and the push of the circulating light on the mirrors.

Residual gas

Radiation pressure

Method and changes from the MATLAB version
  • Ideal gas: Δn = 2πα′Δp/(kBT) with α′ the static polarisability volume (CRC values); Δν/ν = −Δn/n.
  • Local compliance of a half-space under a Gaussian load of 1/e² radius w: χ = (1 − σ²)/(√π E w). Length change ΔL = ΣχiFi plus spacer stretch, with F = (1 + ℛ)P/c on each mirror.
  • Shot noise of the circulating power SP = 2hνPcirc·(T₁ + T₂ + losses)/(1 − r₁r₂)²; laser intensity noise is passed to the circulating power below the cavity pole. Photothermal effects are not included.

Corrected

  • The pressure script converted mbar to Pa twice and used α′p/(2kBT) instead of 2πα′p/(kBT), an 8× overestimate; the temperature was hard-coded to 302.97 K.
  • Reflected and transmitted powers were |E| instead of |E|².
  • The radiation-pressure noise mixed fixed mirrors (𝓕 ≈ 150 000) with a stored finesse of 2093, used a fixed 490 µm beam, and converted white noise with the flicker-noise Allan formula.

Free-running laser noise
Method and changes from the MATLAB version
  • Reflection coefficient (E. D. Black, Am. J. Phys. 69, 79, 2001, generalised to unequal mirrors): F = [−r₁ + r₂(ℛ₁ + T₁)eiφ] / (1 − r₁r₂eiφ), φ = 2πΔf/FSR.
  • Fast-modulation error signal ε = 2√(PcPs)·Im[F(ω)F*(ω+Ω) − F*(ω)F(ω−Ω)] + 2√(PsPs2)·Im[F(ω+Ω)F*(ω+2Ω) − F*(ω−Ω)F(ω−2Ω)]; near resonance ε ≈ −8√(PcPs)·Δf/δν.
  • The simulation uses the static discriminator after a low-pass at the cavity pole δν/2, a discrete PID with trapezoidal integrator, output clamping and band-limited derivative, and adds the correction one time step later. The piezo loop integrates the current-actuator signal so both actuators do not fight over the same error.
  • Laser noise: two Ornstein–Uhlenbeck processes (slow drift, fast jitter) plus an initial offset, generated in the browser from a seeded random-number generator.

Corrected

  • r = √(ℛ₁ℛ₂) was inserted as the amplitude reflectivity, so the simulated cavity had half the finesse.
  • The “integrator” was a 40-sample moving average (no steady-state correction). The derivative used uninitialised history, carried the sign error of the C template it came from, and was never added to the output, so Kd and τ had no effect.
  • Laser noise in Hz was added to an angular frequency in rad/s; the second-order sideband power was read but unused; “lock bandwidth” was a peak-to-peak excursion; the axis labelled µs showed sample numbers.
  • The pre-recorded noise files (.mat) cannot run in a browser; noise with the same character (≈600 kHz slow wander) is generated instead. Gains are now in physical units, so the defaults differ from the old ones.

Notes

How to use the simulator, conventions, and what changed from the MATLAB application.

Using the simulator

  • Every result updates as you type. There is no separate “update values” or “simulate” step.
  • Numbers accept scientific notation (2.5e-6). Type inf or ∞ for a flat mirror.
  • With an input focused, ↑ and ↓ change the value by 1 %; hold Shift for 10 %. For reflectivities the step acts on 1 − ℛ.
  • Each plot has PNG, SVG and CSV export below it; hover a plot for zoom and pan.
  • Copy link puts all parameters into the address, so a colleague opens exactly your cavity. Save parameters and Open parameters use a JSON file, replacing dt.xlsx. The browser also remembers your last session.
  • Everything runs in your browser; nothing is uploaded.

Conventions

  • Radius of curvature R > 0 for a mirror that is concave towards the cavity, R < 0 for convex, ∞ for flat; g = 1 − L/R.
  • ℛ is power reflectivity. Mirror loss (absorption plus scatter) is given separately; transmission is 1 − ℛ − loss.
  • Beam radii are 1/e² intensity radii. Spectral densities are one-sided.
  • Material values are typical figures from manufacturer data and the literature; edit them to match your parts.
